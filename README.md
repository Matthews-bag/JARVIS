# JARVIS

> Personal AI Assistant focused on automation, memory and intelligent tools.

## About

JARVIS is a personal AI assistant project designed to combine artificial intelligence, automation and practical tools in a single system.

The project is being developed as a learning and portfolio project, evolving from a simple AI assistant into a system capable of understanding context, remembering information and executing tasks.

## Planned Features

- AI conversation
- Persistent memory
- Task management
- Web search
- Automation
- External API integrations
- Voice interaction
- Personal productivity tools
